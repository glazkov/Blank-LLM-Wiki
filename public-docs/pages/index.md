# Шаблон проекта LLM Wiki

Этот шаблон помогает запускать проекты, где агент накапливает знания в устойчивой wiki, а не держит важные выводы только в контексте чата.

## Что внутри

- Каркас `raw/`, `wiki/`, `outputs/` и `logs/`.
- Правила работы агента в `AGENTS.md`.
- Стартовые страницы для вводных проекта, текущего состояния и следующих шагов.
- Локальные проверки структуры wiki, orphan-страниц и stale-страниц.
- Опциональный публичный слой для публикации выбранных wiki-страниц.

## Для чего это нужно

Шаблон подходит для исследовательских, личных, рабочих и продуктовых проектов, где знание должно накапливаться постепенно и переживать перезапуски, смену контекста и длинные паузы в работе.
